# Capsule Marusya

Модульный сервер голосового ассистента для **VK Capsule Neo**.

Capsule Marusya заменяет облачную логику обработки голосовых запросов собственной системой, обеспечивая распознавание речи, определение намерений пользователя, выполнение навыков и синтез голосовых ответов.

## Возможности

- **STT (Speech-to-Text)** — распознавание речи и преобразование аудио в текст.
- **VAD (Voice Activity Detection)** — определение начала и окончания голосовой активности.
- **Классификатор** — определение намерения пользователя и выбор подходящего навыка.
- **Skill Registry** — регистрация, хранение и управление навыками ассистента.
- **Skills** — обработка пользовательских запросов, управление функциями устройства и ведение диалоговых сценариев.
- **Context Manager** — управление контекстом диалога и активными навыками.
- **TTS (Text-to-Speech)** — локальный синтез голосовых ответов.
- **Response Protocol** — формирование ответов и команд, совместимых с VK Capsule Neo.
- **HTTP API** — взаимодействие с основным сервером Capsule Neo.

## Архитектура

Обработка голосового запроса проходит несколько этапов:

1. **Audio Input** — получение аудиоданных от устройства.
2. **VAD** — определение окончания пользовательской речи.
3. **STT** — распознавание речи и получение текстовой транскрипции.
4. **Classifier** — определение подходящего навыка.
5. **Skill Handler** — обработка запроса выбранным навыком.
6. **Response** — формирование ответа в формате протокола Capsule Neo.
7. **TTS** — синтез голосового ответа.

## Реализованные навыки

| Навык | Описание |
|---|---|
| `skills_list` | Информация о доступных навыках и возможностях ассистента |
| `voice_repeat` | Повторение произнесённого текста, в том числе в диалоговом режиме |
| `pretty_mode` | Включение и выключение красивого режима |
| `bluetooth` | Включение и выключение Bluetooth |
| `time` | Текущая дата, время и день недели |
| `till` | Обратный отсчёт до событий и значимых дат |
| `calculator` | Выполнение базовых математических операций: сложение, вычитание, умножение, деление, проценты, степени и квадратные корни |
| `unknown` | Обработка запросов, для которых не найден подходящий навык |

Список навыков будет расширяться по мере разработки.

## Требования

- Python 3.11+
- Docker (для контейнерного запуска)

## Установка

Создание виртуального окружения:

```bash
python -m venv .venv
```

Активация окружения:

**macOS / Linux**

```bash
source .venv/bin/activate
```

**Windows**

```powershell
.venv\Scripts\activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

## Конфигурация

Создайте файл `.env` на основе шаблона:

```bash
cp .env.example .env
```

При необходимости измените параметры конфигурации.

## Запуск

Локальный запуск:

```bash
python main.py
```

Запуск через Docker:

```bash
docker build -t capsule-marusya .
docker run -d -p 8090:8090 capsule-marusya
```

## API

После запуска сервера доступны:

- `GET /health` — проверка состояния сервера.
- `/docs` — интерактивная документация API.

Локально документация доступна по адресу:

```text
http://localhost:8090/docs
```

## Интеграция с VK Capsule Neo

Capsule Marusya работает как отдельный сервис и взаимодействует с основным сервером Capsule Neo через HTTP API.

**Capsule Neo** отвечает за:

- Взаимодействие с устройством.
- Получение и транспортировку аудиоданных.
- Передачу запросов на сервер ассистента.
- Получение и воспроизведение ответов.

**Capsule Marusya** отвечает за:

- Распознавание пользовательской речи.
- Определение намерений.
- Выбор и выполнение навыков.
- Управление контекстом диалога.
- Синтез голосовых ответов.
- Формирование ответов в формате устройства.

## Разработка

Проект находится в активной разработке.

Архитектура предусматривает возможность добавления новых навыков без изменения основной логики ассистента.

Каждый навык представляет собой независимый компонент со своей логикой обработки запросов, правилами классификации и примерами пользовательских команд.
