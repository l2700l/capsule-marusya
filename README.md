# Capsule Marusya

Модульный сервер голосового ассистента для VK Capsule Neo.

Проект предназначен для обработки голосовых запросов, распознавания речи, определения намерений пользователя, выполнения навыков и синтеза голосовых ответов.

## Возможности

- **STT** — преобразование речи в текст.
- **Классификатор** — определение намерения пользователя и выбор подходящего навыка.
- **Навыки (Skills)** — обработка пользовательских запросов и выполнение действий.
- **TTS** — преобразование текста в речь.
- **API** — взаимодействие с основным сервером Capsule Neo.
- **Протокол** — формирование ответов и команд, совместимых с VK Capsule Neo.

## Структура проекта

```text
capsule-marusya/

```

## Требования

- Python 3.12+
- Docker (для запуска в составе Capsule Neo)

## Установка

Создание виртуального окружения:

```bash
python -m venv .venv
```

Активация окружения:

**macOS / Linux:**
```bash
source .venv/bin/activate
```

**Windows:**
```powershell
.venv\Scripts\activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

## Конфигурация

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

При необходимости измените параметры конфигурации.

## Запуск

Локальный запуск:

```bash
python main.py
```

Запуск через Docker:

```bash
docker build -t capsule-marusya .
docker run -d -p 8090:8090 capsule-marusya
```

## API

После запуска сервера доступны:

- `http://localhost:8090/health` — проверка состояния сервера.
- `http://localhost:8090/docs` — интерактивная документация API.

## Интеграция с Capsule Neo

Проект предназначен для работы в качестве отдельного сервиса, взаимодействующего с основным сервером Capsule Neo через HTTP API.

Capsule Neo отвечает за взаимодействие с устройством и транспортировку запросов, а Capsule Marusya — за обработку речи, выполнение навыков и формирование ответов.
